02The experiment in 60 seconds

  1. A model is shown all five course pages as raw HTML, order shuffled every trial (controls position bias).
  2. It must recommend exactly one course and justify the pick.
  3. In the same conversation, it then answers an 11-question exit survey: how influential was price, reviews, credentials, badges… (1–5 scale) — asked after the choice, so it is post-choice self-report, not a pre-decision reason.
  4. Repeat 30× per model per page-condition → 1,041 complete trials, CSV-logged with costs, tokens and latencies.

Each page has one strength and one honest tradeoff. No page wins on everything — which page wins depends on what the model's heuristic weights. Browse them: all five pages →

What the models say vs. what they do

“Self-reports track revealed choices closely — Artistry choosers rate credentials 4.99/5 and price 3.30; Palette choosers rate price 5.00/5 and credentials 2.51.”

Caveat, stated deliberately: the exit survey runs after the choice, in the same conversation — it may rationalise a decision already made. The alignment shows consistency between what models say and what they do; on its own it cannot prove the rated factor caused the pick.

Across all 1,041 exit surveys, stated driver importance: Description 4.61 ≈ Reviews 4.56 > Clarity 4.41 > Price 4.03 ≈ Comparison table 3.99 ≈ Credentials 3.96 > Social proof 3.10 > Badge 2.61 > Payment plan 2.24 > Anchoring 2.00. The classic CRO levers — badges, strike-through anchors, installment plans — barely register.

05Run 3 — the rating test

Run 2 left a bundle confound: Canvas's 260 reviews arrived with the lowest rating of the five. Run 3 changes exactly one thing — Canvas's rating 4.3★ → 4.6★ — and re-runs all 7 models with every other feature, and the other four pages, byte-identical.

0.3%Canvas share run 2 · 3 / 1,041 → 26.7%Canvas share run 3 · 55 / 206 206trials of 210 planned · temp 0.1 $6.82run 3 cost cap $100

H1 — rating was the binding constraint: Canvas's share rises well above 0.3%. H2 — the bundle story holds: Canvas stays dead. Result: H1, decisively. A single rating bump lifts the dead page from 0.3% to 26.7% — enough to tie Palette for second. Artistry still wins Run 3 overall (43.7%); no page reaches dominance. The finding is the size of Canvas's jump, not a new winner.

06Surprises & what's next

  • Surprise 1: balance comes from models disagreeing with each other — no model was near-uniform at temperature 0.1. But the pages changed mid-run (16→17 Oct): DeepSeek's own Artistry share moved 94% → 71% across the change while luna and gemini-3.8 stayed stable — so part of the between-model gap reflects which pages each model saw. Full before/after analysis in the write-up.
  • Surprise 2: review volume — the strongest social signal on the Canvas page (260 reviews) — never won a single trial for 6 of 7 models in run 2. Run 3 resolved the ambiguity: with the rating raised off the floor, that same volume wins 26.7% — so volume was never powerless, it was masked by the low rating.
  • Surprise 3: gpt-4.1-mini was the only model producing genuine 5-way variety (picked all five pages) — smaller ≠ simpler heuristics.
  • What's next: a human baseline arm, and frontier (non-low-tier) models to test whether these heuristics hold beyond the low-tier tier.

07Limits

Cost: $54.57 total across all runs (cap $100). Models: 7 low-tier models, one per provider, near-deterministic by design — findings characterize this tier, not frontier models. Pages: fictional courses and synthetic reviews; real brands may behave differently. Drop rate: 9 of 1,050 trials (run 2) and 4 of 210 (run 3) were lost to transient API errors — reported as counts, never imputed.
